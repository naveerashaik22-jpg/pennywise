# PennyWise – Personal Finance Management

PennyWise is a simple and interactive personal finance management web application developed using HTML, CSS and JavaScript.

### Features
- User registration and login
- Personal finance dashboard
- Income and expense tracking
- Transaction history
- Search and category filtering
- Automatic balance calculation
- Local storage for data persistence
- Responsive user interface

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

### How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Register a new account.
4. Log in and start managing transactions.

### Project Purpose
Developed as a Web Technology mini project to demonstrate frontend development, DOM manipulation, event handling and browser storage.
